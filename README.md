# The-Exit-8（漢字8番出口）

ろうかのポスターの漢字をよく見て、まちがいがあれば「引き返す」、なければ「進む」で出口をめざす漢字ゲームです。

## あそび方

- まちがいがあると思ったら「引き返す」を押し、**まちがいの場所をタップ**します。場所を当てられたら正解です。
- まちがいがなければ「進む」を押します。
- 「ヒント」を押すと、見るところがオレンジの枠で出ます（まちがいのないポスターにも枠は出ます）。
- まちがえたあとは「さっきのポスターを確認する」で、まちがいの場所（赤い丸）を見直せます。

| | ふつう | やさしい |
|---|---|---|
| ゴール | 8番出口 | 4番出口 |
| まちがえたとき | 0番出口にもどる | 1つもどる |
| ヒント | 2回まで | 何回でも |
| 場所をタップできる回数 | 2回 | 3回 |
| 出てくるポスター | すべて | `easy: true` のものだけ |

回数などは `questions.js` のいちばん下で変えられます。

## ポスターを追加するとき

1. 画像を `images` に入れます。名前は `種類_ok_01.jpg`（正しいポスター）、`種類_ng_01.jpg`（まちがいのあるポスター）のようにします。
2. `questions.js` にポスターを書き足します。
3. まちがいの場所（`spots`）は、公開ページのURLの後ろに **`/tools/spots.html`** をつけて開くと、自動で見つけてくれます。緑の枠がまちがいの場所になっているか確かめて、「コピーする」で出た文字を `correct: false,` の下にはりつけます。
4. やさしいモードにも出したいポスターには `easy: true,` を書きます。
